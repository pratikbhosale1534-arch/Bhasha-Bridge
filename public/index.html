Responsible AI & your data
  • Translations can be wrong. They are produced by an AI model (IBM Granite). Hindi, Marathi and other Indian languages are not on IBM's official Granite language list, so quality is lower. Have a fluent speaker review anything important, especially formulas, units and numbers.
  • Translation ≠ simplification. “Translate” keeps the meaning and structure. “Simplify” is an AI-written re-explanation that can leave out detail or add mistakes.
  • Your files: processed in server memory only and never saved. Text you translate is sent to IBM watsonx.ai. Only the translated output is kept in history (never the original file), and it is deleted automatically after the retention period or when you delete it.
  • API keys live only in server environment variables and are never sent to your browser.
